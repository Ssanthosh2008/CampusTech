# CampusTech
A mobile-first campus lost & found board for posting, finding, and returning items.
Tech stack: HTML, CSS, vanilla JavaScript ES modules, Supabase.
Open `index.html` with a static server.

Admin access uses the fixed `admin@campustech.local` account; set its password in the Supabase dashboard. Face detection is a best-effort filter; admins are the final check.
